
# Robô Extrator e Conversor de Moedas 🤖📊

## Sobre o Projeto

Este é um script de automação desenvolvido em **Python** que demonstra a integração entre navegação web (Web Scraping) e consumo de APIs em tempo real. O robô foi criado para poupar horas de trabalho manual na coleta e conversão de preços internacionais.

## O que o robô faz automaticamente?

1. Consome uma API financeira para buscar a cotação em tempo real da Libra Esterlina para Dólar (US$) e Real (R$).
2. Abre o navegador sozinho e acessa uma livraria virtual.
3. Extrai o título e o preço original dos livros.
4. Realiza a conversão matemática automática dos valores.
5. Gera um relatório limpo e organizado em Excel (`.xlsx`) com todos os dados prontos para análise.

## Tecnologias Utilizadas

* **Python**
* **Selenium:** Para automação do navegador e coleta de dados.
* **Requests:** Para comunicação com a API de moedas.
* **Pandas:** Para estruturação de dados e geração da planilha Excel.
